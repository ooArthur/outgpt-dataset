1. Cada diretor é responsável pelo orçamento do seu departamento.

3. Remanejamentos entre trimestres do mesmo departamento são aprovados pela Controladoria; entre departamentos, pela CEO.
4. O acompanhamento é feito mensalmente, após o fechamento contábil.
